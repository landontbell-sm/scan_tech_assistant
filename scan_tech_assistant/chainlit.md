# Scan Tech Assistant

Look up a Nessus plugin and get a plain-language explanation of why it fired,
built for the moment you're on a call with a customer and need an answer fast.

**How to use it:** type a plugin ID (the number off the report page) and send it.
The assistant will:

1. Show the plugin's summary and its full NASL source
2. Explain what the plugin checks and what response makes it fire
3. Give you commands to run by hand to confirm or refute the finding, and how to
   read their results

**Then keep going:** ask follow-up questions in the same chat, for example to fix
a command that didn't work or to get the next one. Each chat covers one plugin;
start a new chat for the next one.
